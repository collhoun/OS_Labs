# Лабораторная работа № 5. Вариант 14

Динамические библиотеки в Linux.

## Задание

Нужно реализовать два контракта на C.

| Функция | liblab1.so | liblab2.so |
|---|---|---|
| `float Derivative(float A, float deltaX)` | Правая разность для `cos(x)` | Центральная разность для `cos(x)` |
| `char *translation(long x)` | Перевод в двоичную систему | Перевод в троичную систему |

`program1` подключает `liblab1.so` при линковке. `program2` открывает
библиотеки через `dlopen` и переключает реализации по команде `0`.

## Требования

- Linux, в том числе Linux под WSL.
- GCC с поддержкой C11.
- GNU Make, Bash и `diff`.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `contract.h` | Сигнатуры библиотечных функций |
| `translation.h` | Общий алгоритм перевода числа |
| `lib1.c`, `lib2.c` | Первая и вторая реализации контрактов |
| `common.h`, `common.c` | Общий ввод и обработка команд |
| `program1.c` | Программа с подключением при линковке |
| `program2.c` | Программа с явной загрузкой библиотеки |
| `Makefile` | Сборка, запуск и проверка |

## Сборка и запуск

```bash
make
./program1
```

Для запуска второй программы из каталога проекта используется команда
`./program2`. Также можно запустить программы через `make run`
и `make run-dynamic`.

Сборка создаёт `program1`, `program2`, `liblab1.so` и `liblab2.so`.

## Ввод

Каждая команда вводится с новой строки. Аргументы разделяются пробелами.

| Команда | Действие |
|---|---|
| `1 A deltaX` | Приближённо вычислить производную `cos(x)` в точке `A` |
| `2 x` | Перевести десятичное число `x` в выбранную систему счисления |
| `0` | Переключить библиотеку в `program2` |

Точка и шаг задаются в радианах. Для дробных чисел используется точка.
Шаг должен быть ненулевым. Число `x` должно помещаться в тип `long`.
Для завершения ввода в терминале используется Ctrl+D на пустой строке.

Результаты выводятся в `stdout`, ошибки и сообщения о переключении
выводятся в `stderr`.

## Пример

```bash
printf '1 1 0.1\n2 10\n0\n1 1 0.1\n2 10\n' | ./program2
```

Ожидаемый вывод в `stdout`

```text
-0.867062
1010
-0.840069
101
```

После команды `0` в `stderr` появится сообщение
`Active library: ./liblab2.so`.

## Проверка

```bash
make test
```

Проверка сравнивает вывод обеих программ с ожидаемым. Проверяются обе
формулы производной, перевод положительного и отрицательного числа,
перевод нуля и переключение на вторую библиотеку с возвратом на первую.
При совпадении выводится `Tests passed`.

Зависимости исполняемых файлов можно посмотреть через `readelf` из GNU binutils.

```bash
readelf -d ./program1
readelf -d ./program2
```

Запись `NEEDED` для `liblab1.so` должна быть у `program1`. `program2`
получает доступ к обеим библиотекам через `dlopen` уже после запуска.

## Очистка

```bash
make clean
```
